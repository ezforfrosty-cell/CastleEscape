# Побег из замка

Консольный квест на C#. Игрок сбегает из камеры, ищет ключи, обходит охранника и открывает главные ворота.

## Карта (4 × 3)

```
x:   0      1        2      3
y=0 [камера][ ]  |  [ ]   [ВОРОТА]
y=1 [ ]     [ ]  |  [ ]   [ ]        <- коридор, здесь ходит охранник
y=2 [ ]     [кладовая] | [ ] [оружейная]
```

- Камера (0,0): маленький ключ.
- Кладовая (1,2): аптечка.
- Оружейная (3,2): ключ от главных ворот.
- `|`: запертая дверь между столбцами 1 и 2, открывается маленьким ключом.
- Охранник ходит по строке y = 1 туда-обратно. При встрече отнимает HP (2, 3 или 4 в зависимости от сложности) и разворачивается.

## Команды

| Команда | Действие |
|---|---|
| `w` `a` `s` `d` | вверх / влево / вниз / вправо |
| `осмотр` | обыскать комнату |
| `ждать` | пропустить ход |
| `аптечка` | +4 HP, не выше 10, один раз |
| `открыть` | открыть главные ворота |
| `exit` или `q` | выйти из игры |

## Входные данные для демо

В начале игра спрашивает сложность. Первое число в каждой строке ниже — это ответ на этот вопрос, дальше идут команды.

**Сценарий 1. Ключ и запертая дверь**
`2` → `d` → `d` (дверь заперта) → `a` → `осмотр` (маленький ключ) → `d` → `d` (дверь открылась)

**Сценарий 2. Урон и лечение**
`2` → `осмотр` → `s` → `d` → `s` → `осмотр` (аптечка) → `w` → `ждать` ×4 (два удара: HP 10 → 7 → 4) → `аптечка` (HP 8) → `аптечка` («уже использована»)

**Сценарий 3. Победа**
`2` → `осмотр` → `d` → `d` → `d` → `s` → `s` → `осмотр` (ключ от ворот) → `w` → `w` → `открыть`

**Сценарий 4. Поражение (и HP не уходит в минус)**
`3` → `s` → `ждать` ×12. Удары: HP 10 → 6 → 2 → 0. Последний удар дал бы −2, но HP останавливается на 0.

**Выбор сложности (switch)**
Введи `5`: игра скажет, что такой сложности нет, и выберет нормальную.

**Границы поля**
`2` → `a` («слева стена») → `w` («сверху стена»). Игрок остаётся на месте.

**Неизвестная команда (default)**
Введи `прыгать`: игра скажет, что команда неизвестна, и партия продолжится.

**Выход по команде**
В любой момент введи `q` или `exit`. Игра выведет итоговый счёт, ходы и HP.

**Длинная партия (24 хода, проверка на зависание)**
`1` → `осмотр s d s осмотр w ждать ждать ждать ждать аптечка d d s осмотр w w a a d d w d открыть` → победа

## Почему выбраны именно эти конструкции

- **switch** нужен там, где одна переменная сравнивается с набором констант: команда игрока (`"w"`, `"осмотр"`, `"q"`...) и сложность (`"1"`, `"2"`, `"3"`). Так короче и читается легче, чем длинная цепочка `if (command == ...)`. Ветвь `default` ловит всё, что не распознано.
- **if–else if–else** нужен там, где условия составные или проверяются диапазоны: состояние HP (`hp <= 0` → поражение, иначе ворота открыты → победа, иначе `hp <= 3` → предупреждение), проверки границ, аптечка, открытие ворот. В `switch` такое не записать.
- Порядок ветвей идёт от частного к общему. Сначала `hp <= 0`, потом `hp <= 3`: если поставить их наоборот, ветвь поражения станет недостижимой.

## Граничные случаи

Каждая граница проверяется отдельным условием:
- `if (hp < 0) hp = 0;`: здоровье не уходит в минус;
- `if (hp > maxHp) hp = maxHp;`: аптечка не лечит выше максимума;
- `if (score < 0) score = 0;`: счёт не уходит ниже нуля;
- `newX < 0`, `newX >= width`, `newY < 0`, `newY >= height`: игрок не выходит за поле;
- `gx < 0`, `gx >= width`: охранник разворачивается у стены.

## Игровой цикл (этап 4)

`while (!isWin && !isLose && !isExit)`: цикл крутится, пока не наступила победа, поражение или выход. Все три флага меняются внутри тела цикла:
- `isLose = true` при `hp <= 0`;
- `isWin = true`, когда ворота открыты;
- `isExit = true` по команде `exit` или `q`.

Поле выводится двумя вложенными циклами `for` (по `y` и по `x`).
